Seed Weekly Content → Firebase

One-time migration tool: uploads the weekly lesson files (HTML, audio, CSS, JS) to Firebase Cloud Storage under admin-only paths, then creates Firestore metadata docs for each week. You must run this once after the code ships but before deleting public/weekly/.
