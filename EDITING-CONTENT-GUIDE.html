How to Edit Website Content

No coding experience needed! Follow these steps to update text on the Compassion Course website.

You edit text on GitHub → Site auto-builds → Live in ~2 minutes
1

Open the Content File

Click the link below. You need to be logged into GitHub.

Open siteContent.ts on GitHub
2

Click the Pencil Icon to Edit

Look at the top-right area of the file, in the toolbar row that has "Raw", copy, and download icons. The pencil icon is near the right end of that row.

After clicking the pencil, the page changes to an editor where you can type directly in the file.

3

Find the Text You Want to Change

Press Ctrl + F (or Cmd + F on Mac) and search for the exact text you want to change.

Search for a unique phrase from the website. For example, if the site says "Changing Lives for 15 years", search for exactly that.
4

Edit the Text (Between the Quotes Only!)

Only change the text between the quote marks. Don't touch anything else on the line.

    keyword      change this part      leave
    leave alone  (text inside quotes)   alone
       |                |                 |
       v                v                 v
    heading: 'The Compassion Course',
    ^^^^^^^   ^                    ^^
    DON'T      opening quote    closing quote + comma
    TOUCH      DON'T REMOVE     DON'T REMOVE

Before:

heading: 'The Compassion Course',

After:

heading: 'The Compassion Course - Transform Your Life',
5

Save Your Changes

Click the green "Commit changes..." button in the top-right corner. A dialog box will appear:

  1. Commit message — Write a short note about what you changed (e.g., "Updated hero heading")
  2. Make sure "Commit directly to the main branch" is selected
  3. Click the green "Commit changes" button
6

Verify the Site Updated

After saving, the site automatically rebuilds in about 2 minutes. Check the progress here:

Check Deployment Status

Green circle = Success! Your change is live.
Yellow circle = Still building... wait and refresh.
Red circle = Something broke (see troubleshooting below).

Don't Worry About Spacing

Good news: Indentation and spacing don't matter in this file. The site will work fine even if your lines aren't perfectly aligned. Unlike some programming languages, JavaScript ignores extra spaces. So if your edit looks a little messy compared to the rest of the file, that's totally okay — the site won't break because of spacing.

The Rules

✓ Safe to Change

  • Text inside quotes: 'Hello'
  • Numbers/stats: '14'
  • Descriptions and paragraphs

✗ Don't Touch

  • Keywords before colons: title:
  • Curly braces: { }
  • Square brackets: [ ]
  • Commas at end of lines
  • Icon codes: fas fa-heart
  • File paths: /images/...

Special Characters Cheat Sheet

If your text has these characters inside single quotes '...', use these codes:

CharacterType this insteadExample
’\u2019'it\u2019s great'
“\u201C'\u201CHello\u201D'
”\u201D'\u201CHello\u201D'
…\u2026'Wait\u2026'
—\u2014'life\u2014and love'
Easier option: wrap text in double quotes instead of single quotes if it has an apostrophe: "it's a wonderful course"

Worked Example: Updating a Statistic

The site says "14 Years Running" and you want to change it to "15":

  1. Open the file and press Ctrl+F, search for 14
  2. Find the line:
    { number: '14', label: 'Years Running' },
  3. Change it to:
    { number: '15', label: 'Years Running' },
  4. Click "Commit changes...", write "Updated years to 15", and commit
  5. Wait ~2 minutes, then check the website!

How to undo a bad change

  1. Go to the commit history
  2. Find the commit before yours
  3. Click on siteContent.ts in that commit
  4. Copy all the text, go back to the current file, paste it in, and commit
